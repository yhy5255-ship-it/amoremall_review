이 대시보드는 어떻게 만들어지나요?
  1. 원본 데이터 — Google Sheets를 서비스 계정(읽기 전용)으로 직접 조회합니다.
  2. 집계 — scripts/export_agg.py가 시트 원본을 일(day) × 채널 × 목표 × 기획전 × 소재 단위로 합산해 data.json으로 저장합니다.
  3. 수치 계산 — 이 페이지(app.js)가 data.json을 불러와, 선택한 탭들의 데이터를 합친 뒤 A/B 기간(자유 선택한 날짜 범위)에 맞게 다시 합산하고 ROAS/CPI 증감, 기획전 랭킹, 비중(%)을 브라우저에서 전부 계산합니다.
  4. AI 코멘트 — 계산된 수치 + 특이사항 메모를 /api/comment(Vercel 서버리스 함수)로 보내고, 그 함수가 Gemini API를 호출해 사람이 분석한 것 같은 코멘트를 받아옵니다. API 키는 서버 환경변수에만 있고 브라우저에는 노출되지 않습니다. 매출_KPF 상세성과만은 예외로, AI 없이 규칙 기반으로 그대로 계산됩니다.

data.json을 불러오지 못했습니다

이 페이지는 fetch()로 같은 폴더의 data.json을 읽습니다. 파일을 더블클릭해 여는 file:// 방식으로는 브라우저가 fetch를 막을 수 있습니다. AI 코멘트(/api/comment)까지 로컬에서 테스트하려면 vercel dev로 실행해주세요 — npx serve는 정적 파일만 서빙해서 API 라우트가 동작하지 않습니다. (Vercel에 배포하면 둘 다 문제 없이 동작합니다.)
