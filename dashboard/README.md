# 아모레몰 주간 광고성과 대시보드

탭(월)과 자유로운 A/B 날짜 범위를 골라 광고 성과를 비교하고, 우수 기획전 랭킹과 목표(매출/신규가입/앱설치/트래픽)별 AI 코멘트를 자동 생성하는 대시보드. 계산된 수치를 근거로 자유롭게 질문할 수 있는 Q&A 패널도 있다.

## 구조

```
dashboard/
  index.html          페이지 골격 + "이 대시보드는 어떻게 만들어지나요?" 설명 패널
  style.css           스타일
  app.js              data.json을 불러와 비교/랭킹/비중(%)을 브라우저에서 계산하고,
                       /api/comment(코멘트)·/api/qa(Q&A)·/api/refresh(데이터 최신화)를 호출
  api/comment.js      Vercel 서버리스 함수 — 계산된 수치 + 특이사항 메모를 Gemini로 보내 목표별 코멘트 생성
  api/qa.js           Vercel 서버리스 함수 — RAW 데이터를 근거로 자유 질문에 답변 (컨텍스트 캐싱 지원)
  api/refresh.js       Vercel 서버리스 함수 — 시트를 다시 읽어 최신 데이터를 브라우저 세션에 반영 ("데이터 최신화" 버튼)
  data.json            (gitignored) 시트 스냅샷 — scripts/export_agg.py의 출력물
  scripts/export_agg.py Google Sheets -> data.json 집계 스크립트 (일 단위 집계)
  package.json         @google/genai, google-auth-library 의존성
```

데이터 흐름: **Google Sheets → (서비스 계정, 읽기 전용) → export_agg.py가 일(day) 단위로 집계 → data.json → app.js가 선택된 탭(들)을 합치고 A/B 날짜 범위로 재집계해 비교/랭킹/비중 계산 → api/comment.js(서버)가 그 수치 + 메모를 Gemini API에 보내 코멘트 생성**. 매출_KPF 상세성과만은 예외로, AI 없이 규칙 기반으로 그대로 계산된다.

## 로컬에서 보기

정적 파일뿐 아니라 서버리스 함수(`/api/comment`, `/api/qa`, `/api/refresh`)도 있어서, `npx serve`나 더블클릭(`file://`)으로는 이 기능들이 동작하지 않는다 (data.json은 읽히지만 AI 코멘트/Q&A/데이터 최신화는 실패한다). **Vercel CLI로 실행할 것.**

```
npm install -g vercel      # 최초 1회
cd dashboard
npm install                # @google/genai, google-auth-library 설치
cp .env.example .env.local # GEMINI_API_KEY 값 채워넣기 (https://aistudio.google.com/apikey 에서 발급)
vercel dev
```

`vercel dev`는 정적 파일과 `api/` 폴더의 서버리스 함수를 함께 로컬에서 서빙한다. `data.json`만 확인하면 되고 AI 기능이 필요 없다면 `npx serve .`도 괜찮다.

## 분석 탭 · 기간 선택

- **탭**: 사이드바의 멀티셀렉트 드롭다운(Ctrl/Cmd+클릭)에서 하나 이상의 월 탭을 고른다. 여러 탭을 함께 고르면 월 경계를 넘는 기간(예: 6/29~7/5)도 하나의 데이터 풀로 합쳐서 비교할 수 있다.
- **A/B 기간**: 주차 프리셋이 아니라 자유로운 시작일~종료일을 직접 고른다. 입력 가능한 범위는 선택된 탭(들)의 실제 데이터 범위로 제한되고, 탭 선택을 바꾸면 즉시 갱신된다. "최근 7일 vs 이전 7일" 버튼으로 빠르게 채울 수 있고, A/B가 겹치면 경고가 뜬다.
- 내부적으로는 `scripts/export_agg.py`가 만든 일(day) 단위 원본을 `app.js`가 선택된 날짜 범위 안에서 기존과 동일한 병합 키(채널/목표/매체/브랜드/기획전/상태)로 재집계한다 — 그래서 리포트 섹션, 차트, AI 코멘트, Q&A 등 다운스트림 로직은 데이터가 한 주였든 임의 기간이었든 코드 변경 없이 그대로 동작한다.

## 데이터 새로고침

두 가지 방법이 있다.

**1) 화면의 "데이터 최신화" 버튼** — `/api/refresh`가 시트를 다시 읽어 그 결과를 브라우저 세션에만 반영한다. `data.json` 파일 자체는 바꾸지 않으므로, 새로고침하면 다시 스냅샷(`data.json`) 기준으로 돌아간다. 배포된 환경에서 쓰려면 서비스 계정 키를 `GOOGLE_SERVICE_ACCOUNT_KEY_JSON` 환경변수(키 파일 전체 JSON)로 등록해야 한다 (`.env.example` 참고) — Vercel 함수는 로컬 파일 경로를 못 읽기 때문. 로컬 `vercel dev`에서는 `scripts/export_agg.py`와 같은 키 파일 경로를 그대로 재사용해서 별도 설정 없이 동작한다.

**2) 스냅샷 자체를 갱신** — `data.json`을 다시 굽고 싶을 때(예: git에 커밋하지 않더라도 로컬 기본값을 최신으로 유지하고 싶을 때):

```
pip install google-api-python-client google-auth
python scripts/export_agg.py
```

기본적으로 `scripts/export_agg.py` 안의 `KEY_PATH`를 사용하며, `GOOGLE_SERVICE_ACCOUNT_KEY` 환경변수로 다른 키 파일 경로를 지정할 수도 있다. 새로운 월 탭(예: `2608`)이 추가되면 스크립트의 `TABS` 리스트에 이름을 추가하고, **`api/refresh.js`의 `TABS` 상수도 같이 맞춰줘야 한다** (두 파일이 독립적으로 유지된다).

## AI 코멘트 (`/api/comment`)

- **트리거**: 사이드바에서 "특이사항 메모"(선택 입력, B기간별로 `localStorage`에 자동 저장)를 쓴 뒤 "분석 시작"을 누르면, 계산된 수치 + 메모가 `/api/comment`로 전송된다.
- **섹션**: 매출/신규가입/앱설치/트래픽 4개 목표(BL 열 기준)별로 각각 코멘트가 생성된다.
- **모델**: `gemini-3.6-flash` (기본값, `GEMINI_MODEL` 환경변수로 변경 가능), structured output(JSON 스키마)으로 호출한다. 프롬프트와 참고 체크리스트는 `api/comment.js`에 있다.
- **근거 배지**: 각 코멘트 문장에는 그 근거가 데이터 수치(`data`)인지, 사용자의 특이사항 메모(`note`)인지, AI의 추정/해석(`inference`)인지를 나타내는 작은 색점이 붙는다 (화면에만 표시, 복사 텍스트에는 안 보임).
- **KPF 예외**: "매출_KPF 상세성과"는 AI가 만들지 않는다. 발송 건수·매출·ROAS가 전부 합산으로만 나오는 값이라 규칙 기반으로 그대로 계산해서, AI가 반환한 매출 섹션의 "매출" 리드 바로 뒤에 끼워 넣는다.
- **복사 포맷**: "코멘트 복사" 버튼은 AI가 반환한 JSON(섹션→리드→디테일 구조)에서 직접 텍스트를 만든다 — 우수 기획전 TOP5(`[INSIGHT]`)는 화면에는 계속 보이지만 복사 텍스트에서는 제외된다.
- **실패 시**: AI 호출이 실패하면 각 섹션에 오류 메시지 + "다시 시도" 버튼이 나타난다 (데이터 재계산 없이 마지막 페이로드로 재호출). 이 경우 "코멘트 복사"는 빈 텍스트를 조용히 복사하는 대신 "복사할 코멘트 없음"으로 표시된다.

## AI Q&A (`/api/qa`)

- 리포트 화면의 "AI에게 질문하기" 버튼으로 여는 사이드 패널. `/api/comment`와 별개로, **선택된 탭·A/B 기간의 RAW 데이터**를 근거로 자유 질문에 답한다.
- **토큰 절감 - 질문별 최소 전송**: 질문 텍스트에서 목표(매출/신규가입/앱설치/트래픽) 키워드나 브랜드/기획전명을 감지해 관련 있는 목표만 추려 보내고, 브랜드+기획전 단위로 집계해서 보낸다. 매체/채널 언급이 있을 때만 채널 단위 상세를, "소재" 언급이 있을 때만 소재 단위 데이터를 추가로 포함한다. 애매하면 4개 목표 전부 포함(정확도 우선).
- **토큰 절감 - 컨텍스트 캐싱**: 세션의 2번째 질문에서만 전체 RAW 데이터를 한 번 실어 보내 Gemini 컨텍스트 캐시(TTL 30분)를 만들고, 이후 턴부터는 캐시 이름만 재사용한다(데이터 재전송 없음). 캐시가 만료/실패하면 자동으로 최소 데이터 기반 호출로 폴백한다. 탭/기간을 바꿔 "분석 시작"을 다시 누르면 Q&A 히스토리와 캐시 참조가 초기화된다.
- **표 첨부**: 여러 기획전/매체를 비교하는 질문이면 답변 아래에 표가 자동으로 붙는다.
- **환각 방지**: 사실과 해석 구분, 상관관계≠인과관계, 데이터 범위를 벗어나면 "모릅니다" 응답 등 원칙이 `api/qa.js`의 system prompt에 있다.

## 데이터 최신화 (`/api/refresh`)

`scripts/export_agg.py`의 집계 로직을 Node.js로 그대로 이식한 버전이다 (필드/카운트 일치 검증됨). Vercel 배포 환경은 파일시스템이 읽기 전용이라 `data.json`을 덮어쓸 수 없으므로, 이 엔드포인트는 최신 데이터를 응답으로 반환해서 브라우저가 현재 세션에서만 쓰게 한다 — 다음 페이지 로드 시 기본값으로 남을 스냅샷을 갱신하려면 여전히 `python scripts/export_agg.py`를 실행해야 한다.

## 알려진 스코프

- **앱설치 기획전 비교**: Google(AC) 매체만 기획전 단위로 비교한다. ASA는 기획전명이 전부 `iOS` 하나로 통합돼 있어 기획전별 비교가 불가능하기 때문. ASA는 매체 특성상 첫구매/회원가입 집계가 원천적으로 불가능해 값과 무관하게 "확인 불가"로 표시된다 (Google은 집계 가능).
- **우수 기획전 TOP5**: 목표(매출/신규가입/앱설치/트래픽)와 정렬 기준(ROAS/첫구매 수/첫구매 CPA/회원가입 수/회원가입 CPA)을 드롭다운으로 바꿀 수 있다.
- **혼합형 비교 차트**: 세부 데이터의 "전주 대비 비교" 토글은 A/B 각 기간의 top-N 합집합을 기획전(브랜드+기획전명) 기준으로 매칭해서, 신규 진입/순위이탈/종료를 배지로 구분해 보여준다.

## Vercel 배포

이 폴더는 정적 파일 + `api/` 서버리스 함수 구조라 Vercel에 그대로 배포할 수 있다 (별도 빌드 설정 불필요, `package.json`의 의존성만 자동 설치됨). 배포 전 확인할 것:

1. Vercel 프로젝트 설정(Environment Variables)에 `GEMINI_API_KEY`를 등록한다. 브라우저에는 절대 노출되지 않는다.
2. "데이터 최신화" 버튼을 배포 환경에서도 쓰려면 `GOOGLE_SERVICE_ACCOUNT_KEY_JSON`(서비스 계정 키 파일 전체 내용)도 등록해야 한다.
3. `data.json`은 실제 매출/광고비가 담긴 민감 데이터라 `.gitignore`에 포함되어 있다 — GitHub에 푸시하기 전에 이 저장소를 비공개로 둘지, 아니면 `data.json`을 커밋하지 않고 별도의 안전한 방법으로 채울지 정해야 한다.
